# To-Do List Application ✓

A modern, feature-rich to-do list application with local storage functionality. Built with HTML, CSS, and vanilla JavaScript.

## Features

### ✨ Core Features
- ✅ **Add Tasks** - Quickly add new tasks with Enter key support
- ✅ **Mark Complete** - Check off completed tasks
- ✅ **Delete Tasks** - Remove individual tasks
- ✅ **Filter Tasks** - View All, Active, or Completed tasks
- ✅ **Local Storage** - All tasks automatically saved to browser storage
- ✅ **Statistics** - See total, completed, and remaining tasks at a glance

### 🎨 Design Features
- Beautiful gradient background
- Smooth animations and transitions
- Responsive design (works on mobile, tablet, desktop)
- Clean and intuitive user interface
- Task dates automatically added

### 🚀 Additional Features
- Clear all completed tasks with one click
- Clear all tasks option
- Empty state message
- Task persistence across browser sessions
- Real-time statistics updates

## How to Use

1. **Open** `index.html` in your web browser
2. **Type** your task in the input field
3. **Press Enter** or click "Add Task" button
4. **Check** the checkbox to mark task as complete
5. **Click Delete** to remove a task
6. **Use Filters** to view different task categories
7. **Your tasks are automatically saved** to local storage

## Local Storage

All your tasks are automatically saved to your browser's local storage. This means:
- Tasks persist even after closing the browser
- Each browser/device has its own separate task list
- No account or login required
- Data is stored locally on your computer
